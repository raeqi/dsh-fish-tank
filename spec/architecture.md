# 鱼缸当前架构与数据边界

本文描述 DSH 鱼缸插件在 v2.1 玩法基础上接入模块化客户端后的实际源码结构，不把视觉目标或未验证的服务当成已部署能力。支持的游戏状态为 version 3 / featureVersion 2；保留 18 个稳定鱼种索引、育苗、来客、收藏、水草、小龟和可选捕猎。代码与图需要共同维护：[可编辑架构图](architecture.drawio)。

## 运行角色和职责

1. **DSH 宿主**加载插件并提供客户端模块加载器、React、侧栏/主页面插槽、语言包与会话投影；Host 的 Web 服务提供受认证保护的路由。
2. **客户端入口** `src/entry.js` 组合依赖并注册页面。`src/ui/page.js` 负责交互、状态发布和 Host 同步，`src/ui/use-tank-canvas.js` 管理画布、帧循环、尺寸、减少动效与释放；`src/host/usage.js` 将 DSH 会话投影转换为用量条目。
3. **鱼缸模拟**位于客户端 `src/core/`：`store.js` 编排生命周期、游戏与存档，`state.js` 读取/校验状态，`ledger.js` 计算用量奖励，`motion.js` 与 `effects.js` 更新运动和瞬态效果。`src/shared/` 维护数值工具和稳定鱼种索引。当前 `store.js` 仍承担多个领域职责，`state.js` 的默认存储读取仍触及浏览器全局，解耦尚可继续完善。
4. **渲染**由 `src/renderer/scene.js` 组合背景、灯光、植物、鱼群、粒子与玻璃。三组鱼图集和其他素材由构建内嵌；优先 WebGL 图集网格，失败时回退 Canvas 2D 图集切片，素材不可用时回退程序绘制。鱼超过 32 条时降低网格密度，不删除数据。减少动效固定视觉运动并降低绘制频率，模拟仍按页面生命周期执行。
5. **Host 端** `index.js` 在 `/fish-tank/state` 上提供 GET/HEAD/POST，默认把 JSON 文件存至 `DSH_HOME/fish-tank/tank.json`，也可配置绝对路径。`account-source.js` 是可选账号用量与云存储适配层；默认没有可用账号总用量接口或已部署云存档。

`client.js` 是由 `src/` 与素材生成的自包含 DSH 入口，运行时不请求远程图片或 npm 包；不要直接修改生成物。`npm run build` 生成它，`npm test` 构建并运行功能、回归和页面测试。

## 核心数据流

- 会话用量：DSH `useSessions` → `host/usage.js` → `core/ledger.js` → 储备、自动投喂与寻访进度；首次观察到的每个会话被当作基线。可选账号用量接入后以账号累计值代替本机会话估计。
- 用户操作：页面按钮或画布投喂 → `core/store.js` → 鱼食与鱼群/玩法状态 → 场景数据 → 渲染；状态同时用于页面展示和持久化。模拟是业务结果的来源，模型或动画不是执行成功证据。
- 本地保存：浏览器 `localStorage` 缓存同一快照，客户端通过受认证的 Host 路由读取/写回 JSON；新旧状态按现有时间戳和格式检查处理。旧格式升级时保留浏览器备份，鱼食、鱼群、收藏、进度和用量基线随快照保存。
- 可选云存储：明确配置 HTTPS 服务、宿主凭据与账号后，由 Host 适配器按账号和 revision 通信；非本机 HTTP 被拒绝，本机回环地址是测试例外。没有配置时是本机模式，不宣称跨设备云同步。

## 失败与一致性边界

- 无法读取浏览器存储、数据损坏或状态 `version` 高于支持版本时，客户端不会将新鱼缸覆盖原缓存；Host 文件解析失败时接口报错。本地保存失败会在页面提示，Host 读写失败时同步状态降级为本地；不能把内存状态当成持久成功。对较新的 `featureVersion` 的保护以 Host 校验为准，浏览器读取尚未单独检查该字段。
- 浏览器在写前比较快照可以拦截顺序发生的旧写入，但比较与写入不是原子操作；Host 在同一文件对象内排队并以临时文件替换 JSON，但没有验证跨进程/多机器互斥。时间戳及该队列不构成全局并发安全保证。
- 会话列表仍在加载且未报错时不提交离线结算；会话不可用或报错时可以使用已有储备继续结算。离线跨度目前最多结算 14 天。新会话首次观察被当作基线，`ids` 不含的子会话可能漏算；这些是现有限制。
- WebGL 或图片失败时应继续展示状态和可用操作；页面卸载释放渲染资源。图集鱼体近似体积，环境为静态背景与效果合成，不是完整三维、独立骨骼或 PBR 场景。
