# 鱼缸规范索引

本目录记录 DSH 鱼缸插件的当前架构、开发要求、视觉目标与验收证据。它以现有 v2.1 玩法及其模块化客户端为范围：主机 JSON 和浏览器缓存是默认存储，账号用量与云存储仅在配置真实服务后可用。18 种鱼和育苗、水草、小龟等玩法已经实现；完整三维与 3A 视觉目标尚未完成。

- [架构与数据边界](architecture.md)：运行角色、模块、关键数据流和当前限制；[可编辑架构图](architecture.drawio)是同一现状的视觉视图。
- [视觉需求](visual-requirements.md)：目标效果、能力边界与未完成的验收。
- [开发与验证规范](development.md)：核心链路、解耦、性能、持久化与文档维护的合并要求。
- [当前验收证据](acceptance.md)：受测版本、测试结果、真实 DSH 检查和未验证范围。

规范将已实现行为、预期目标和实测证据分开描述；功能测试通过不代表性能或真实宿主验收通过。开发索引见仓库根目录 `agent.md`。
