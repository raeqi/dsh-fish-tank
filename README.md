# 鱼缸

在 DSH 左侧栏养一缸鱼。消耗的 token 会攒成自动鱼食；你也可以随时手动投喂。

## 规则

- **手动投喂永远可用**：点「投喂」撒 3 粒，点水面撒 1 粒，不消耗储备。鱼吃饱后会忽略食物，多余的鱼食会沉底。
- **自动鱼食来自 token**：**10,000 token = 1 粒**，进入自动储备。token 取各会话累计用量（含缓存读取），第一次打开鱼缸时只记录基线，不补发历史鱼食。
- 自动储备只在鱼饿时使用：页面开着时，有饿鱼且水里没有鱼食，会每 5 秒自动撒 1 粒；离开期间按储备结算。现在每条鱼大约吃 **25 粒/天**（3 条约 75 粒/天，8 条约 200 粒/天），比最初快约 8 倍。
- 饥饿约 **24 小时**到顶。鱼饿到顶后持续 **72 小时** 会死亡，所以离开时如果储备不够，大约 **4 天**就会失去一条鱼；回来手动喂可以救下还活着的鱼。
- 鱼吃食会长大（手动或自动都算）。成年鱼吃够 **8 粒**后，若 12 小时内没有生过，会生下一条小鱼，鱼最多 **8 条**。
- 关闭鱼缸后，下一次打开会按离开的时间结算：自动储备喂食、成长、生小鱼，以及饿死。只剩空缸时可以免费放入一条新鱼苗。
- 所有状态只保存在当前浏览器（`localStorage`，键 `dsh.fish-tank.v1`），换浏览器或清除站点数据会重新开始。

## 画面

- 水景参考自然草缸：深绿水体、两侧高低错落的茎草与阔叶水榕、右侧红色茎草、带木纹的分叉沉木、岩石与细沙缓坡，中间留出游动空间。
- 六种鱼使用为本项目生成的写实透明素材：**蓝白大理石斗鱼、红龙孔雀鱼、锦鲤神仙鱼、宝莲灯、蓝松石七彩神仙、荷兰凤凰**。每条鱼保留完整花纹、细鳞反光与薄透鱼鳍；成长影响体型，饥饿降低饱和度。
- 鱼鳍保持静止。动态采用整体滑行、轻微起伏、平滑转向、转身收窄与近邻避让；靠近玻璃提前转身，追食时加速，不同鱼种巡游速度不同。
- 图集存放于 `assets/tropical-fish-atlas.webp`，坐标与品种顺序见同目录 JSON；Client 中内嵌同一份 WebP，适配模块加载器，运行时不需要联网或独立资源路由。图片加载期间及无 Image API 环境使用程序绘制回退。
- 保留投食水花、吃食涟漪、出生闪光、死亡下沉淡出、水面反光、气泡和水底投影。写实素材不单独变形张嘴。
- 旧存档的前四个鱼种索引保持一致；新增七彩神仙和荷兰凤凰追加到末尾。新鱼缸初始为七彩神仙、孔雀鱼和锦鲤神仙鱼。喂食兑换、饥饿、繁殖和离线结算规则保持一致。

## 用法

- 点击左侧栏的「鱼缸」打开。
- 随时可以「投喂」或点水面；想攒自动储备就正常使用 DSH。
- 页面底部分别累计**自动投喂**和**手动投喂**的粒数（离开期间消耗自动储备算自动投喂），并显示自动储备、鱼缸启用后累计的 token，以及兑换比例。

## 测试

```sh
node --test test/fish-store.test.mjs
DSH_CHECKOUT=/path/to/dsh-checkout node --test test/panel-flow.test.mjs
```

`fish-store` 同时跑一次渲染冒烟测试：用桩 2D 上下文把整个鱼缸和每种鱼各画一遍，并检查六种写实鱼图集的裁切、平滑转向、帧率一致性及新增鱼种存档。
`panel-flow` 需要从 DSH 源码 checkout 借用 jsdom 和 Testing Library；没有 `DSH_CHECKOUT` 时会跳过。

替换图集后运行 `node scripts/embed-fish-atlas.mjs` 同步 Client 内嵌素材。

## 调参

比例、饥饿速度、死亡时限、生育门槛等常量在 `client.js` 顶部（`DshFishTank` 的 `TOKENS_PER_PELLET`、`HUNGER_RATE`、`STARVE_MS`、`BIRTH_PELLETS` 等）。
